# Fake News Detector
A machine learning project that detects whether a news article is real or fake.

## What I built
- Trained a model on 1000+ real news articles
- Used TF-IDF to convert text into numbers the model can understand
- Logistic Regression classifier with 78% accuracy

## How to run
1. Clone this repo
2. Install requirements: `pip install pandas scikit-learn matplotlib jupyter`
3. Open `notebooks/week1_baseline.ipynb` and run all cells

## Results
| Model and Accuracy |
| Logistic Regression (baseline) | 78% |
| DistilBERT (coming week 2) | ~90% |
